A Python program — standard library only, no network — that writes one line to /output/entry.txt: an office joke about the printer announcing its retirement and serving its two weeks' notice as two solid weeks of paper jams. The line is 129 characters, inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
